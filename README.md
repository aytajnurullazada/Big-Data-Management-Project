# Big Data Management – Course Project

This repository contains the final project for the Big Data Management course.
The project consists of four independent sub-projects, each focusing on a
different aspect of large-scale data processing and analysis.

## Project Overview

### Project 1 – Batch Data Analytics (NYC Taxi Data)
- Batch analysis of NYC taxi trip data
- Data cleaning and aggregation
- Analysis of trips within and across boroughs
- Calculation of average time to next fare

Folder: `project-1-batch-analytics`

---

### Project 2 – Streaming Data Analytics
- Processing and analysis of streaming data
- Real-time aggregation and metrics computation

Folder: `project-2-streaming-analytics`

---

### Project 3 – Clustering and Recommendation
- Unsupervised learning and clustering
- Similarity-based recommendation logic

Folder: `project-3-clustering-recommendation`

---

### Project 4 – Federated Learning
- Distributed machine learning setup
- Model training across multiple clients

Folder: `project-4-federated-learning`

---

## Files
- Each project folder contains a Jupyter notebook (`main.ipynb`)
- Processed datasets for Project 2 are stored in the `data/` subfolder
- `ProjectPresentation.pptx` contains the final presentation slides
